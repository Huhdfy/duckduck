# 四组续训实验（2026-10-28）

四组均从 rerun 的 6000 轮检查点独立接续训练 4000 轮，训练种子为 123，终点文件为 `model_9999.pt`：

- ① baseline：保持原配置。
- ② 权重 4.0：线速度、角速度跟踪奖励权重均改为 4.0。
- ③ std 0.15/0.35：线速度、角速度跟踪奖励的 std 分别改为 0.15 和 0.35。
- ④ 关节惩罚：增加带逐关节容差的目标角与实际角跟踪误差惩罚。

评估采用相同环境和种子，每档 16 次试验、每次 20 秒，排除前 3 秒。以下同时展示原 6000 轮模型作为参照；本轮仅使用一个训练种子。

## 总体收益与代价

各项误差均为越低越好，虚线为续训 baseline，括号显示相对 baseline 的变化。收紧 std 改善速度跟踪但明显增大偏航；关节惩罚减小关节误差，却让机器人走得更慢。

## 分速度档表现

圆点表示单次试验的平均前向速度，菱形表示 16 次均值，虚线表示目标速度。权重组在低速档大量停滞，关节惩罚组在高速档明显偏慢。
